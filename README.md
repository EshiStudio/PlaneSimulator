# PlaneSimulator

Веб-приложение на three.js: белый клетчатый бесконечный пол (клетка 10 м) для
понимания объёма и перемещения, и модель биплана WW1 с рабочим винтом,
элеронами и рулём высоты.

## Запуск

ES-модули и GLTFLoader не работают с `file://` — нужен HTTP-сервер:

```
python -m http.server 8000
```

Затем открыть http://localhost:8000/index.html

## Управление

| Клавиша | Действие |
|---|---|
| W / S | руль высоты вверх / вниз (±20°) |
| A / D | элероны: крен влево / вправо (±22°, дифференциально) |
| Стрелки | самолёт на соседнюю клетку, нос поворачивается по движению |
| Пробел | запуск/остановка двигателя |
| ЛКМ + мышь | орбита камеры вокруг самолёта и её высота |
| Колесо | дистанция камеры (3–100 м) |
| Q / E | высота камеры (0.5–40 м) |
| R | сброс камеры |

Поверхности удерживаются отклонёнными, пока клавиша нажата, и плавно
возвращаются в нейтраль. Системы полёта пока нет: самолёт стоит на земле,
двигаются только сами поверхности.

## Структура

```
index.html        разметка, importmap, подключение src/main.js
src/main.js       точка входа: связывает модули, главный цикл, HUD
src/scene.js      рендер, свет, бесконечная земля (сетка в шейдере), тени
src/camera.js     камера преследования за хвостом
src/plane.js      загрузка GLB, парковочная стойка, винт, поверхности
src/input.js      клавиатура и мышь
src/constants.js  размер клетки, пределы камеры
src/status.js     оверлей загрузки/ошибок
lib/              three.js 0.170.0 локально (офлайн)
assets/           модель самолёта и текстуры
tools/            страницы проверки (не часть приложения)
```

## Проверка

- `tools/selftest.html` — собирает самолёт без рендера и печатает в консоль
  состав поверхностей и их углы при разном вводе. Ожидается `элеронов: 4`,
  `шарниров руля высоты: 1`, отклонения ±22° / ±20° и возврат в ноль.
- `tools/visual.html?pitch=1&view=tail` — рендер для визуальной проверки
  (`pitch`/`roll` = 1 или -1, `view` = `tail`, `rear`, `close`).
- `tools/dump.html?rear=-0.30` — габариты мешей модели в её собственных
  координатах: этим находились панели крыльев и хвоста.

## Важные детали

- У `lib/GLTFLoader.js` импорт `BufferGeometryUtils.js` переписан с `../utils/`
  на `./` — иначе браузер ловит 404 и модель не грузится.
- Модель ориентирована **носом по +Z**, хвостом по −Z.
- Пороги разбора элеронов (`x > 0`, `y > 0.3`) заданы в **собственных
  координатах модели**, не в мировых: в мировых они ломаются масштабом (×5.7)
  и сдвигом самолёта в центр клетки.
- Поверхность сидит на ДВУХ вложенных узлах: внешний держит выравнивание оси
  (`quaternion`), вложенный отклоняет (`rotation.x`). Совмещать нельзя —
  в three.js это одно состояние, и присваивание `rotation.x` стирает
  выравнивание.
- У хвостового оперения нет своей контурной оболочки: его контур входит в общую
  `polySurface308_Tooner_0`. Треугольник оболочки достаётся ближайшему к нему
  мешу — по габаритам панели резать нельзя, оболочка раздута наружу почти на
  полметра. Иначе на месте отклонённого руля остаётся чёрное пятно.
- Контурная оболочка `Tooner` выступает вниз почти на 0.5 м и исключена из
  расчёта масштаба, посадки на пол и отбрасывания теней.
